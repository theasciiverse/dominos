# Roadmap

Dominos is at 0.5.0 (2026-10-28): the three games it promises are complete,
with computer players and play on the local network. 1.0.0 is when
everything below is in.

## 0.5.0: built

- [x] The Block game, the Draw game and All Fives, chosen on the menu
- [x] Two to four players, partners at four (sitting opposite)
- [x] The computer at three strengths
- [x] Local network play: the host runs the game, tables found by LAN
  broadcast or a typed address, empty seats filled by the computer, the
  host moves players between seats
- [x] Keys and mouse, help (F1 or ?), `--demo`
